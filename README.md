🎨 AI Virtual Painter

Real-Time Hand Gesture-Based Drawing Application

AI Virtual Painter is a computer vision-based application that allows users to draw on a digital canvas using hand gestures in real time. By utilizing webcam-based hand tracking, the application provides a touchless and interactive painting experience.

✨ Features

- 🖐️ Real-time hand tracking using a webcam
- 🎨 Gesture-based drawing on a virtual canvas
- 🌈 Interactive painting experience
- 🖥️ Desktop graphical user interface
- 💾 Save artwork for future use
- ⚡ Real-time gesture detection and processing

🛠️ Technologies Used

- Python – Core programming language
- OpenCV – Image processing and webcam access
- MediaPipe – Hand landmark detection and tracking
- NumPy – Numerical operations and canvas processing
- Tkinter – Desktop graphical user interface
- Pillow (PIL) – Image handling and display

⚙️ Installation

1. Clone the Repository

git clone YOUR_REPOSITORY_URL

2. Navigate to the Project Folder

cd AI-Virtual-Painter

3. Install Dependencies

pip install opencv-python mediapipe numpy pillow

4. Run the Application

python main.py

Replace "main.py" with your actual Python filename if it is different.

🚀 How It Works

1. Launch the application.
2. Allow access to your webcam.
3. Show your hand in front of the camera.
4. Use the supported hand gestures to interact with the canvas.
5. Draw and create digital artwork without touching the screen.

🎯 Project Objective

The objective of this project is to demonstrate how artificial intelligence and computer vision can enable natural, touchless interaction between humans and computers.
